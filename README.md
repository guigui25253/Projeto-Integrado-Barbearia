# Studio Corte & Estilo – Sistema de agendamento (Projeto Integrado)

Protótipo em Python 3 + Flask + SQLite.

## Como executar
    pip install flask
    python app.py        # abre em http://127.0.0.1:5000
    python testes.py     # executa os casos de teste

Login de demonstração: usuário `atendente`, senha `1234`.
